# Student Life App - Aplikasi Manajemen Aktivitas Mahasiswa

## Deskripsi Aplikasi

Student Life adalah aplikasi yang dirancang untuk membantu mahasiswa dalam mengelola kegiatan akademik dan keuangan mereka secara efisien. Aplikasi ini memiliki empat fitur utama:

- **Tambah Jadwal Kuliah**
- **Catat Tugas Kuliah**
- **Catat Pengeluaran Harian**
- **Rekomendasi Tempat Belajar**

### Fitur Utama

- Input data seperti jadwal kuliah, tugas, rekomendasi tempat belajar dan pengeluaran dengan antarmuka yang minimalis dan elegan.
- Upload gambar pendukung
- Edit data yang telah diinput
- Hapus data yang telah diinput
- Pengelolaan data menggunakan **RecyclerView** dan **Custom Adapter** untuk menampilkan daftar data.
